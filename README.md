# 🌐 语跃 LinguaLeap

> **一门外语，一次跃迁。**
> 一个覆盖 **英语 / 日语 / 韩语** 的多语种语言学习平台原型。

`单文件` · `零依赖` · `原生 HTML / CSS / JavaScript` · `离线可用` · `MIT License`

---

## 📖 项目简介

**语跃 LinguaLeap** 是一个面向语言学习者的沉浸式学习平台前端原型。它把「选课 → 学词 → 练语法 → 开口说 → 听理解 → 循环复习」的完整学习闭环，浓缩进一个可以直接用浏览器打开的单文件应用中。

平台内置 18 节分级课程、单词闪卡与间隔重复、双语课文阅读、学习打卡、语法练习、口语跟读、听力训练、学习进度可视化、个性化学习路径与定级测试、学习社区与成就体系。所有数据保存在浏览器本地，打开即学，无需服务器、无需安装依赖。

> 本项目为**前端演示原型**：界面、交互与数据逻辑完整可体验，但不包含真实后端服务。

## ✨ 项目亮点

- **单文件即全部** —— 页面结构、设计系统、交互逻辑与全部课程数据都封装在一个 `index.html` 中。
- **零依赖、离线可用** —— 不引入任何框架、构建工具或外部 CDN，断网也能完整使用（语音能力除外）。
- **完整学习闭环** —— 单词、语法、口语、听力四大环节 + 双语课文阅读 + 间隔重复复习 + 打卡与进度反馈，形成可坚持的学习节奏。
- **克制的视觉设计** —— 米白纸感底色 + 浅蓝主色，干净留白、细边框与轻阴影，接近 Figma 稿的教育类界面质感。
- **本地优先的数据** —— 用户、进度、复习计划、阅读记录、社区内容均存于 `localStorage`，隐私数据不出浏览器。

## 🚀 功能特性

### 一、分级课程体系

覆盖 3 门语言 × 3 个级别，共 **18 节**课程，每门语言按级别以 3 / 2 / 1 节分布：

| 语言 | 级别与课程数 |
| --- | --- |
| 🇬🇧 英语 | A1 入门（3 课）→ A2 基础（2 课）→ B1 进阶（1 课） |
| 🇯🇵 日语 | N5 五级（3 课）→ N4 四级（2 课）→ N3 三级（1 课） |
| 🇰🇷 韩语 | TOPIK Ⅰ（3 课）→ TOPIK Ⅱ（2 课）→ TOPIK Ⅲ（1 课） |

每节课固定包含 **单词 / 语法 / 口语 / 听力** 四个学习环节，内容配比为 8 个核心词汇（个别高级课 6 个）、3 道语法题、2 句跟读、3 道听力题；四环节全部完成后课程标记为已完成，并解锁「继续下一课」与进阶提示。

### 三、课文阅读（新增）

- **不额外维护课文数据**：每节课的「2 句跟读 + 3 条听力原文」自动汇编成约 5 句的双语课文，共 18 篇；可从侧边栏「课文阅读」或课程学习页的「预览本课课文」进入；
- **双栏阅读布局**：左侧支持英语 / 日语 / 韩语切换，逐课显示级别、句数与已读状态；右侧为阅读区；
- **朗读辅助**：支持全文朗读 / 停止、逐句朗读，发音贴合当前语言，可随时中断；
- **中译对照**：一键显示或隐藏中文译文，先理解再核对；
- **生词即点即查**：正文中本节课的生词以虚线标注，点击弹出音标、释义、例句与发音，底部同步提供本课生词 chips；
- **阅读记录**：标记已读（首次 +5 XP，记录阅读进度，首页入口显示「已读 x / 18」），不影响原有课程进度与复习队列。

### 排版、空间与组件

- 系统字体栈 `-apple-system` / `Segoe UI` / `PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`，不加载 Web Font；正文 14–15px，行高约 1.7–1.9；
- 圆角：卡片 **18px**，大面板 24px，按钮 12–14px，小元素 8–12px；卡片统一「1px 细边框 + 极轻阴影」，无重投影与大面积渐变；
- 留白：视图内边距 34–40px，卡片内边距 26px，栅格间距 20px；
- 响应式：`≤900px` 侧边栏折叠为 68px 图标栏；`≤700px` 顶栏换行、首页与课文阅读改为单列，移动端可完成全部流程；

## 🏁 快速开始

本项目**无需构建、无需安装依赖**，两种方式任选其一：

- **方式一：直接打开** —— 双击 `index.html`，用浏览器打开即可，适合快速预览界面与流程。
- **方式二：本地静态服务（推荐）** —— 语音识别需要安全上下文（`localhost` 或 HTTPS），通过本地服务访问体验最完整：

```bash
# 进入项目目录后启动一个静态服务器
python3 -m http.server 8080
# Windows 亦可使用
py -m http.server 8080
```

然后浏览器访问 <http://localhost:8080>，推荐使用最新版 **Chrome / Edge**。

## 🛠 技术实现

| 方面 | 实现方式 |
| --- | --- |
| 架构 | 单文件原生前端：HTML + CSS + Vanilla JavaScript，无框架、无构建步骤、无外部 CDN |
| 路由 | 基于内存状态的自研视图切换（`go(view)`），配合本地会话管理登录态 |
| 数据持久化 | `localStorage`：用户、会话、学习进度（含阅读记录）、复习队列、社区帖子分别存储 |
| 语音能力 | Web Speech API：`speechSynthesis` 按语言映射 `en-US / ja-JP / ko-KR`；`SpeechRecognition` 多候选识别，失败自动降级 |
| 发音评分 | 字符级 **Levenshtein 编辑距离** 计算相似度（0–100），先去除标点与空白再比较 |
| 间隔重复 | 莱特纳式记忆盒：5 个阶段，间隔 1 / 2 / 4 / 7 / 15 天，答错重置 |
| 课文阅读 | 复用课程已有的跟读句与听力原文，运行时自动汇编为双语课文，无额外数据维护 |
| 图表 | 纯手写 SVG 折线图、SVG 环形进度、CSS Grid 热力图与打卡格，无图表库 |
| 激励体系 | XP 规则 + 13 级等级阈值 + 成就条件引擎 + 连续打卡状态机 |
| 安全与隐私 | 所有数据仅保存在浏览器本地；密码仅做演示级哈希，不作为真实安全方案 |

**内容体量**：18 节课程 · 18 篇课文（约 90 句）· 142 个核心词汇 · 18 个语法知识点 · 54 道语法题 · 36 句跟读 · 54 道听力题 · 13 枚成就 · 5 类社区话题 · 10 位排行榜学习者。

## 📌 说明与限制

- **纯前端演示项目**：没有后端服务，注册、登录、进度、阅读记录与社区数据都只保存在当前浏览器的 `localStorage` 中，不会上传到任何服务器；
- **更换浏览器 / 设备 / 清理浏览器数据**会导致本地数据丢失，演示账号会在再次访问时自动重新生成；
- **口语跟读**依赖浏览器的语音识别能力，需要 `localhost` 或 HTTPS 环境并授予麦克风权限；在不支持的浏览器中会自动切换为自评模式；
- **语音朗读**依赖操作系统已安装的语音包，不同系统下的音色与可用性可能不同；
